# Plans et spécifications conservés

Ce répertoire porte le nom d'un ancien outil de planification. Ses documents
conservent les décisions de conception, les critères de recette et l'historique
des lots ; certains travaux restent référencés dans `docs/tasks/NEXT_ACTIONS.md`.

Aucun plugin Superpowers ni assistant particulier n'est requis pour les utiliser.
Pour exécuter un lot, suivre les règles actuelles de [`AGENTS.md`](../../AGENTS.md)
et les commandes de [`STACK_AND_COMMANDS.md`](../context/STACK_AND_COMMANDS.md).
Les anciens blocs `REQUIRED SUB-SKILL`, options de sandbox, comptes de tests et
checklists ne constituent pas une preuve de l'état actuel du code.

Le workflow de vérification réglementaire est désormais documenté dans
[`VERIFICATION_WORKFLOW.md`](../agents/chomage/VERIFICATION_WORKFLOW.md).
Les fichiers de configuration Claude décrits dans les plans du 20/07/2026 ont
été remplacés par cette procédure ; ne pas les recréer.
