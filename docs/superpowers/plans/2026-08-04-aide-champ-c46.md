# Couverture de l'aide de champ — C46 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Compléter l'aide de champ du C46 (2 champs sans `help` sur 10 —
`nom_et_pr_nom`, `organisme3`), premier document du chantier « couverture de
l'aide de champ » — le plus petit, pour calibrer le processus avant le C1A.

**Architecture:** Chantier de **contenu sourcé**, pas de code. Ajout de
`help: { fr: "..." }` sur des champs de seed existants ; le mécanisme
d'affichage (`ContextHelpPanel`/`pickFieldHelp`) est déjà en place et
inchangé. Spec validée :
`docs/superpowers/specs/2026-08-04-couverture-aide-de-champ-design.md`.

**Tech Stack:** aucun — édition de `lib/pdf-forms/seed/c46-fields.ts` (objets
littéraux TypeScript), rien d'autre.

## Global Constraints

- **Aucun texte inventé.** Chaque aide est recopiée du PDF officiel
  (`private/pdfs/C46_FR.pdf`) ou dérivée par cohérence stricte d'un champ
  jumeau déjà documenté (ex. `organisme2`↔`organisme3`) — jamais improvisée.
- Un champ sans texte imprimé pertinent **reste sans aide**, avec une note
  expliquant pourquoi — pas de phrase creuse pour gonfler la couverture.
- Ce lot ne touche **que** `help` sur des champs existants : aucun `id`,
  `pdfFieldName`, `order`, `visibleIf` ne change.
- `git add` de chemins **explicites** uniquement (workdir partagé
  multi-agents).
- `pnpm lint` a ~129 erreurs préexistantes : zéro nouvelle erreur (ce lot ne
  devrait de toute façon toucher aucun fichier lintable autrement qu'en JSON
  de configuration TS — vérifier quand même).
- **Le contenu n'atteint l'écran qu'après re-semis**
  (`pnpm tsx scripts/apply-c1-improvements.ts --yes`, base partagée) —
  lancement laissé à Oraliks, comme toute évolution de `C1_IMPROVEMENT_TARGETS`.
- Commandes de validation : `pnpm vitest run lib/pdf-forms/seed/__tests__/c46-fields.test.ts` ·
  `pnpm build` · `pnpm lint`.

`private/pdfs/C46_FR.pdf`) :

  (ces) organisme(s). Il doit s'agir d'un organe consultatif du secteur

  d'un bloc à mandats multiples) — même patron, adapté au rang.
- `nom_et_pr_nom` : le PDF n'imprime **aucun texte explicatif** autour du
  libellé « Nom et prénom » (juste le label et la ligne pointillée). Rien à
  recopier ; le laisser sans aide est le choix le plus honnête — cf.
  Global Constraints.

- [ ] **Step 1: Ajouter l'aide sur `organisme3`**

Dans `lib/pdf-forms/seed/c46-fields.ts`, le champ :

```ts
  {

    alignTextToGuide: true,
    type: "text",
    required: false,
    label: { fr: "Nom de l'organisme (mandat 3)" },
```

```ts
    alignTextToGuide: true,
    type: "text",
    required: false,
    label: { fr: "Nom de l'organisme (mandat 3)" },
```
